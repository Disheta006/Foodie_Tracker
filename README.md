# 🍕 Foodie Tracker

A simple food order tracking web app built using HTML, CSS, and JavaScript.

## 🎮 Features

- Enter customer name
- Select food
- Place an order
- Track order progress
- Simulate food preparation and packing
- Random delivery partner assignment
- Handle order failure
- Retry failed orders
- Place another order after completion
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Promises
- Async/Await
- DOM Manipulation

## 🕹️ Order Flow

```text
Place Order
     ↓
Restaurant Confirmed
     ↓
Food Prepared
     ↓
Food Packed
     ↓
Rider Assigned
     ↓
Order Delivered
```

## 🧠 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
